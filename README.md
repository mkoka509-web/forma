# ФормаДесерт

## Описание проекта
«ФормаДесерт» — настольное приложение для просмотра и управления каталогом кондитерских изделий. Приложение разработано на Python с использованием PySide6 и PostgreSQL.

## 1. Необходимые программы

Для запуска проекта на новом компьютере необходимо установить:

- Python 3.10 или новее (рекомендуется Python 3.15).
- PostgreSQL 18.
- pgAdmin 4.
- Visual Studio Code (рекомендуется).

## 2. Скачивание проекта

1. Открыть GitHub.
2. Скачать проект или клонировать репозиторий через GitHub Desktop.
3. Открыть папку `forma` в Visual Studio Code.

## 3. Создание виртуального окружения

Открыть терминал в VS Code и выполнить:

```powershell
python -m venv .venv
```

## 4. Установка библиотек

Выполнить команду:

```powershell
.venv\Scripts\python.exe -m pip install -r requirements.txt
```

## 5. Настройка базы данных PostgreSQL

1. Открыть pgAdmin 4.
2. Подключиться к серверу PostgreSQL.
3. Нажать правой кнопкой мыши на Databases.
4. Выбрать Create → Database.
5. Назвать базу данных `my_project`.
6. Нажать Save.

## 6. Восстановление базы данных

В корневой папке проекта должен находиться файл `my_project.backup`.

Для восстановления:

1. Нажать правой кнопкой мыши на базу `my_project`.
2. Выбрать Restore.
3. Указать файл `my_project.backup`.
4. Выбрать формат Custom.
5. Нажать Restore.

После восстановления в базе должны появиться таблицы проекта и данные каталога.

## 7. Настройка подключения к базе данных

Открыть файл:

`src/app/database.py`

Проверить настройки подключения:

```python
host="localhost",
port=5432,
database="my_project",
user="postgres",
password="ВАШ_ПАРОЛЬ"
```

Вместо `ВАШ_ПАРОЛЬ` указать пароль пользователя PostgreSQL, установленный на новом компьютере.

## 8. Запуск приложения

1. Убедиться, что сервер PostgreSQL запущен.
2. Открыть папку проекта в VS Code.
3. Открыть Terminal → New Terminal.
4. Выполнить команду:

```powershell
.venv\Scripts\python.exe -m src.app.main
```

После выполнения команды должно открыться главное окно приложения «ФормаДесерт».

## 9. Возможные проблемы

**Ошибка подключения к PostgreSQL**

Проверить:
- Запущен ли сервер PostgreSQL.
- Правильно ли указано имя базы данных.
- Правильно ли указан пароль.
- Работает ли сервер на порту 5432.

**Ошибка отсутствующих библиотек**

Повторно выполнить:

```powershell
.venv\Scripts\python.exe -m pip install -r requirements.txt
```

**Приложение не запускается**

Проверить, что терминал открыт в корневой папке проекта и команда запуска введена правильно.

---

## Важно

- Файл `my_project.backup` необходим для восстановления базы данных.
- Виртуальное окружение `.venv` на другой компьютер переносить не нужно — оно создаётся заново.
- Пароль PostgreSQL на каждом компьютере может отличаться.
- Не удалять резервную копию базы данных.
- Не публиковать реальные пароли и конфиденциальные данные в открытом GitHub-репозитории.
